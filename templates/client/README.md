# __APP_TITLE__

React + Vite + TypeScript + Tailwind, made with `create-kamyar`.

```bash
npm install
npm run dev
```

| Command          | What it does                  |
| ---------------- | ----------------------------- |
| `npm run dev`    | Dev server on localhost:5173  |
| `npm run build`  | Type-check and build          |
| `npm run lint`   | ESLint                        |
| `npm run format` | Format `src/` with Prettier   |

Conventions and folder structure are in [CLAUDE.md](CLAUDE.md).
